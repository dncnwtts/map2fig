## What Was Built

### 1. CLI Backend Selection
```bash
cargo run -- -f map.fits -o output.pdf --pdf-backend printpdf
```

### 2. Architecture
- PlotData struct carries `pdf_backend: String`
- `plot_mollweide_auto()` routes to appropriate backend
- Cairo: 300ms, vector overlays, compressed (500KB)
- Printpdf: ~254ms, raw image, uncompressed (1.3MB)

### 3. Benchmark Results

| Aspect | Cairo | Printpdf | Improvement |

## Performance Breakdown

**Cairo Rendering (300ms):**
```
Rendering: 201ms (67%)
  ├─ HEALPix projection: 107ms
  ├─ Colormap/scaling: 83ms  
  └─ Other: 11ms
PDF finalization: 99ms (33%)
  ├─ zlib compression: 10ms
  ├─ PDF encoding: 8ms
  └─ I/O: 15ms
```

**Printpdf (254ms):** Same rendering (201ms) + RGB conversion (3ms) + uncompressed write (50ms)

**Savings: 46ms = 15.3% improvement**
