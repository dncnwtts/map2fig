# HEALPix Plotter Documentation

This directory contains organized documentation for the HEALPix Plotter project.

## Structure

### 📐 [architecture/](architecture/)
Detailed design documents and technical specifications:
- **Projection designs**: Mollweide, Hammer, Gnomonic
- **Rendering**: Graticule, SVG implementation, LaTeX integration
- **Layout & Scaling**: Figure sizing and coordinate systems

### 🛠️ [development/](development/)
Development guides and setup instructions:
- **Build & Test**: Requirements, setup procedures
- **Benchmarking**: Performance testing guide
- **CLI**: Command-line interface documentation

### 📊 [reports/](reports/)
Test results, verification reports, and comparisons:
- **Test Results**: Integration tests, comparisons with healpy
- **Quality Verification**: Determinism checks, PDF/PNG analysis
- **Graticule Reports**: Visual quality and correctness checks

### 📚 [history/](history/)
Session notes, completed work, and development archives:
- Development session summaries
- Refactoring records and migration notes
- Completed features and fixes
- Old debug scripts (archived for reference)
